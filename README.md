
# Just Get To The Other Side

*No tomfoolery or trickery here! It's so simple! Just get to the other side!*

This game is a basic platformer except the game lies to you constantly and you can't trust it. The game has many surprises, changes in game mechanics that it lies about, and signs that lead you in the wrong direction. To succeed in the game, you must not trust the game or take it at its fullest word. This game was made for the Brackeys Game Jam 2026.2.
